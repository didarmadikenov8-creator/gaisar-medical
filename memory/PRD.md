# MEDICA — Landing Page шаблон частного медицинского центра

## Оригинальный запрос
Одностраничный сайт-шаблон (DEMO) для частного медицинского центра: premium medical минимализм, светлый фон, глубокий тёмно-синий + спокойный бирюзовый акцент, без AI-slop эстетики. Цель — мотивировать запись через WhatsApp или форму. Секции: Header (sticky), Hero, блок доверия, Услуги (6), Врачи (4), О центре, Процесс 01–04, Отзывы (DEMO), FAQ (5), CTA, Контакты с картой, Footer. Функционал: плавный scroll, мобильное меню, accordion FAQ, modal-форма записи, floating WhatsApp-кнопка, валидация.

## Решения пользователя (уточнения)
- Форма записи отправляет заявку в WhatsApp: wa.me/77473100916 с текстом «Здравствуйте! Хочу записаться на приём. Имя: … Телефон: … Направление: …»
- WhatsApp-кнопки (шапка/плавающая/CTA): wa.me/77473100916 с сообщением «Здравствуйте! Хочу узнать подробнее об услугах медицинского центра.»
- Карта: Google Maps embed, локация «ЖК Alma City 5, Алматы»
- Без выдуманных лицензий и медицинских обещаний; врачи/отзывы — явно помеченный демо-контент

## Архитектура
- Frontend: React (CRA + craco), Tailwind, framer-motion (reveals, parallax, modal, accordion), lenis (smooth scroll, window.__lenis), sonner (toasts), lucide-react (иконки)
- Шрифты: Cormorant Garamond (display, кириллица) + Plus Jakarta Sans (body)
- Палитра: #F8FAFC фон, #0F2C59 navy, #0D9488 teal, #0F172A ink, #475569 steel, #E2E8F0 line
- Backend (FastAPI) не задействован: заявка формируется целиком на клиенте и уходит в WhatsApp deep-link. Существующий /api остаётся без изменений.
- Ключевые файлы: src/lib/site.js (константы WA/телефон/карта), src/context/AppointmentContext.jsx (модалка), src/components/* (Navbar, Hero, TrustMarquee, Services, Doctors, About, Process, Reviews, Faq, CtaBand, Contacts, Footer, AppointmentModal, FloatingWhatsApp, Reveal)
